# Explain Anything

Type a concept, or snap a photo of a sketch, formula or textbook page, and get back a hand-built interactive explanation: animated hero, live simulation with sliders, step-by-step walkthrough, the math, common misconceptions, real-world examples and a short quiz.

Pages are generated by Google's Gemini API and rendered in a sandboxed iframe.

## Features

- **Text input**: type any concept ("how do black holes bend light?").
- **Photo input**: use the camera or upload an image; the generated page recreates what is in the photo and makes it interactive.
- **Regenerate**: ask for a fresh take on the same input.
- **Make it simpler**: rewrite for a curious 12-year-old, with fewer controls and less math.
- **Model picker**: `gemini-flash-latest` (default), `gemini-pro-latest` (paid tier only) or `gemini-flash-lite-latest`. The choice is saved in your browser.
- **Streaming progress**: shows the model's thinking headings, a live line count and the page source as it is written.
- **Caching**: finished pages are stored in `localStorage` per concept or photo, so repeat requests load instantly.
- **Light and dark UI**, following your system setting.

## Requirements

- A [Gemini API key](https://aistudio.google.com/apikey)
- Any static file server. There is no build step and no dependencies to install.
- A modern browser. Camera capture needs a secure context, which `localhost` counts as.

## Getting started

1. Copy the example config and add your key:

   ```bash
   cp config.example.js config.js
   ```

   Then edit `config.js`:

   ```js
   window.GEMINI_API_KEY = "your-key-here";
   ```

   `config.js` is gitignored, so the key stays out of version control.

2. Serve the folder over HTTP:

   ```bash
   python3 -m http.server 8000
   ```

3. Open <http://localhost:8000>.

The repo also includes a `.claude/launch.json` entry (`explain-anything`) that starts the same server for Claude Code's preview.

## How it works

Everything lives in [`index.html`](index.html):

1. The UI is styled with Tailwind (CDN build) and the Geist and Instrument Serif fonts.
2. On submit, the page calls `streamGenerateContent` on the Gemini API directly from the browser. A long system prompt tells the model to return one complete HTML document structured as an "explorable explanation", in the spirit of Distill.pub and Nicky Case.
3. The streamed response is cleaned of markdown fences and stray text, and a shared design kit (dark theme, CSS variables, component classes, KaTeX auto-render) is injected into its `<head>`.
4. The result is set as the `srcdoc` of an iframe with `sandbox="allow-scripts"`, so generated code runs isolated from the host page.

Generated pages may load Three.js, D3, p5.js, Matter.js, GSAP or Chart.js from a fixed list of CDN URLs.

## Security note

The API key is read in the browser and sent straight to Google, so anyone who can open the page can see it. Use this on your own machine only. Don't deploy it publicly with a real key in `config.js`.

## Troubleshooting

- **"Missing Gemini API key"**: create `config.js` as described above and reload.
- **"The page was cut off before it finished"**: the model hit its output limit. Click *Try again*.
- **Camera won't open**: serve the page from `localhost` or HTTPS and allow camera access.
- **Stale or bad result**: click *Regenerate* to bypass the cache. To clear everything, delete this site's `localStorage` entries starting with `viz:`.
- **`gemini-pro-latest` errors**: it requires a paid-tier API key.
